# First-party prospecting dataset boundary

The uploaded institutional prospecting workbook is a research/operations asset, not a public truth source for GlobeSpark country pages.

## Public-safe
- Aggregated, verified statistics when they add genuine user value and pass privacy/relevance thresholds.
- Official institution facts only after authoritative verification and provenance capture.

## Private/gated
- Fit score, tier, strategic path, recommended contact roles, outreach angle, first-message type, risk note, next action and source task IDs.
- Raw discovery descriptions until sanitized and verified.

## Forbidden by default
- Personal email harvesting, family/student identifiers, private contacts, unverified partnership claims, automated outreach based only on priority score.

Any future Organizations Intelligence module must have a separate index/storage boundary, access policy, audit log and human verification gate.
